# کاتالوگ دیجیتال ماشین‌سازی نادری

کاتالوگ لوکس با قابلیت ورق‌زدن واقعی (Page Flip) برای معرفی ماشین‌آلات صنایع غذایی.

## ویژگی‌ها

- ظاهر لوکس با پالت رنگی سرمه‌ای + طلایی + کرم
- افکت ورق‌زدن نرم و واقعی
- کاملاً فارسی و راست‌چین
- ریسپانسیو (موبایل و دسکتاپ)
- لینک مستقیم به ابزار برآورد قیمت و واتساپ
- آماده برای GitHub Pages

## نحوه اجرا روی سیستم خودتان

فقط فایل `index.html` را در مرورگر باز کنید.

## انتشار روی GitHub Pages

1. یک ریپازیتوری جدید در گیت‌هاب بسازید (مثلاً `naderi-catalog`)
2. تمام محتویات این پوشه را آپلود کنید
3. به Settings → Pages بروید
4. Source را روی `main` branch و پوشه `/ (root)` تنظیم کنید
5. چند دقیقه صبر کنید تا آدرس فعال شود:
   `https://USERNAME.github.io/naderi-catalog/`

## نحوه ویرایش محتوا

### تغییر متن‌ها
فایل `index.html` را باز کنید و متن‌های داخل تگ‌های `<p>` و `<h2>` و `<h3>` را ویرایش کنید.

### اضافه کردن عکس واقعی دستگاه‌ها
1. عکس‌ها را داخل پوشه `assets/images/` قرار دهید
2. در `index.html` بخش‌های `img-placeholder` را با تگ `<img>` جایگزین کنید:

```html
<div class="product-image">
  <img src="assets/images/candy-cutter.jpg" alt="دستگاه برش آبنبات لاکچری" style="width:100%;height:100%;object-fit:cover;border-radius:4px;">
</div>
```

### اضافه کردن صفحه جدید
یک `<div class="page">...</div>` جدید قبل از صفحه آخر (صفحه تماس) اضافه کنید و شماره صفحات را به‌روز کنید.

## ساختار فایل‌ها

```
naderi-catalog/
├── index.html          ← صفحه اصلی کاتالوگ
├── css/
│   └── style.css       ← استایل‌های لوکس
├── js/
│   └── main.js         ← منطق ورق‌زدن
├── assets/
│   └── images/         ← عکس‌های دستگاه‌ها (اینجا قرار دهید)
└── README.md
```

## نکات

- کتابخانه PageFlip از CDN لود می‌شود (نیازی به نصب نیست)
- برای بهترین تجربه، عکس‌ها را با نسبت تقریبی ۳:۴ و کیفیت خوب آماده کنید
- رنگ‌ها و فونت‌ها در فایل `css/style.css` قابل تنظیم هستند
